# EmptyState

部品ページ（/guidelines/components/empty-state/）の手書き節。実装から機械的に出せない「振る舞い」「内容（文言）」「参考文献」だけを書く。
概要・アンチパターン・推奨例・使用例は `src/components/ui/empty-state/index.tsx` の JSDoc が正。

## 振る舞い

- 中身は中央寄せの縦積みで、上下 32px（`py-8`）の余白が入る。高さは中身なりなので、一覧の領域と同じ高さにしたいときは親で最低の高さを決める。
- マスコットは 96px で、そのとき選ばれているテーマの猫が出る（`useNekoTheme`）。テーマを切り替えると絵も変わる。
- カードの中や表の脇のような狭い領域では `hideMascot` を渡す。マスコットが無くても成り立つよう、文言だけで意味が通る見出しにする。
- 見出しのレベルは `headingLevel`（2 / 3 / 4、既定 3）で画面の見出し階層に合わせる。見た目の大きさは変わらないので、階層だけを合わせればよい。
- 説明は 36 文字幅（`max-w-[36ch]`）で折り返す。2 行を超えるときは説明ではなく見出しを見直す。
- `action` に渡す Button は 1 つだけにする（主アクションは 1 画面 1 つ）。2 つ出したくなったら、片方は一覧の上のツールバーに置く。

## 内容

- 見出しは〈対象〉＋〈無い〉の形にする（「まだ案件がありません」「条件に合う案件がありません」）。「データがありません」のように対象を省かない。
- 説明は「何をすればここに出るようになるか」を 1 文で書く（「最初の案件を追加すると、ここに一覧が表示されます。」）。
- アクションの文言は見出しと対応させる。初回 0 件は「案件を追加する」、検索結果 0 件は「条件をクリアする」。
- 読み込みの失敗を EmptyState にしない。原因があるときは InlineMessage（negative）＋「再試行する」にする。
