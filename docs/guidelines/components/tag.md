# Tag

部品ページ（/guidelines/components/tag/）の手書き節。実装から機械的に出せない「振る舞い」「内容（文言）」「参考文献」だけを書く。
概要・アンチパターン・推奨例・使用例は `src/components/ui/tag/index.tsx` の JSDoc が正。

## 振る舞い

- 高さは Tag 28px / StatusTag 24px で固定。行に合わせて縮まないので、表のセルに入れるときは行の高さを 1 行ぶん余らせる。
- 文言は折り返さず、親の幅を超えると末尾が `…` になる。省略すると意味が変わる条件名は、親側で最大幅を決めるか語を短くする。
- `Tag` 自体は `<span>` でフォーカスも当たらない。`onRemove` を渡したときだけ右端に 20px の × ボタンが付き、そこだけがキーボードで押せる。
- × を押しても Tag は自分では消えない。条件の配列から外すのは呼び出し側の仕事なので、外した直後は一覧の件数も同時に更新する。
- `StatusTag` は文字の前に 6px の点が付き、色と文字の両方で状態を示す。`status` は info / success / warning / negative / neutral の 5 つだけで、分類の色分けには使わない。

## 内容

- 絞り込み条件の Tag は「項目名: 値」で書く（「状態: 進行中」）。値だけを置くと何の条件か分からなくなる。
- `StatusTag` の中身は状態名だけ（「進行中」「完了」「確認待ち」「差し戻し」）。「ステータス: 完了」と項目名を重ねない。
- `removeLabel` の既定は「外す」。同じ画面に条件が複数並ぶときは対象を入れる（「状態: 進行中 を外す」）。
- 状態の語は画面のあいだで揃える。同じ状態を一覧では「完了」、詳細では「終了」と書き分けない。
- 条件の Tag を並べる順は、利用者が指定した順に固定する。件数が変わるたびに並べ替えない。
